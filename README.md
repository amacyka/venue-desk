# Срез P2P

Терминал смотрит публичные P2P-объявления USDT. Площадки не смешиваются.

Живые источники: Binance P2P и Bybit P2P. Binance — турецкая лира и индийская рупия. Bybit — те же две валюты и российский рубль. Рубль Binance в терминал не входит. Средняя цена — весь стакан, вес по остатку USDT. На Bybit первая страница в эту среднюю не входит. Рядом остаются наборы 50, 100, 500 и 1000 USDT и глубина у лучшей цены. Ликвидность на карточках — объём в пределах 1%. Число объявлений без фильтра оплаты берётся из размера списка. Оборот завершённых сделок эти API не отдают.

Хрокет и Crypto Bot показаны как неподключённые источники. Их курсы в терминал не подставляются.

История графика — только сохранённые срезы сервера, не чаще раза в минуту. Файл `data/p2p-history.json` в git не входит.

## Запуск

```bash
cd venue-desk
npm install
cp .env.example .env
npm run dev
```

Пульт: http://127.0.0.1:44721

## Telegram

Тот же срез в боте, без графиков.

```bash
cd venue-desk
# TELEGRAM_BOT_TOKEN от @BotFather в .env
npm run bot
```

Бот: https://t.me/AMACY_Analytics_bot

Если в `.env` указан публичный `WEBAPP_URL` с https, у бота появляется кнопка «Терминал» и кнопка «Открыть терминал». Они открывают этот экран как Mini App. Адрес `http://127.0.0.1` в кнопку не ставится: телефон его не видит.

Проверка разбора ответов:

```bash
npm test
```
